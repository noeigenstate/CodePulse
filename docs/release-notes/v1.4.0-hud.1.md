## v1.4.0-hud.1

### HUD 预发布版

- 同一项目中的 Claude、Codex、Kimi 与 Grok 各自显示为独立卡片，状态、计时、上下文、
  注意动效和“已读”互不干扰。
- 同项目卡片在单列和紧凑矩阵两种布局下都纵向聚合，并以克制的共享细框标明归属；
  单 agent 项目继续保持原有布局。
- Kimi CLI 在应用启动后才开始运行时，也会通过 hook 触发受节流的账户额度刷新，
  恢复 HUD 底部的 Kimi 用量显示。
- 发布号明确标记为 HUD 预发布版；带连字符的版本标签会发布为 GitHub prerelease，
  不会替代正式稳定版的 Latest 标记。

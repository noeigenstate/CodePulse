## v1.7.0

### 更新内容

- 悬浮窗（HUD）改版，新增四种样式：灵动岛（屏幕顶部一颗胶囊）、胶囊流（每个任务一颗胶囊）、边缘抽屉（屏幕右边缘一条窄标签）、悬浮球（可拖到任意位置，位置会记住）。在「控制 → HUD → HUD 样式」里切换，立即生效；原来的面板保留，仍是默认样式
- 提醒分级：出错是红色三角，等你处理是橙色圆点，已完成是绿色对勾，运行中是蓝色转圈，不看颜色也能靠形状分辨。出错和等你处理的提醒会一直显示，直到状态变化；完成提醒显示 5 秒后收起，未读标记保留
- 新样式的透明区域不挡鼠标，点击会直接落到下面的窗口。Linux 下暂不支持穿透，透明区域仍会挡住点击；新样式在 macOS 上尚未实机验证
- 新增「有提醒时自动显示 HUD」选项，默认关闭。开启后，HUD 收起时来了新提醒会自动出现，且不抢键盘焦点
- 修复：HUD 设置窗口里改的选项之前会被覆盖还原，现在会保存
- Windows 关闭「动画效果」时，转圈和脉冲会停止，但胶囊变形动画保留

# CodePulse hardware / 硬件设计

此处为硬件贡献者的发布入口。

| 板型与修订                               | 已上传                           | 状态                                     |
| ---------------------------------------- | -------------------------------- | ---------------------------------------- |
| [main-board/v3](main-board/v3/README.md) | Gerber、原理图 PDF、STEP、渲染图 | 未经实机验证；源文件、BOM 和许可证待上传 |

建议按 `hardware/<board>/<revision>/` 保存独立板型和不可混淆的 PCB 修订：

```text
hardware/<board>/<revision>/
  README.md          板型、修订、适配固件、验证状态、供电/烧录说明
  LICENSE            贡献者确认的硬件设计许可证
  src/               可编辑原理图、PCB、库和结构件源文件
  bom/               BOM及必要的替代料说明
  exports/           对应这版源文件的PDF、Gerber等导出物
```

上传时请在该 revision 的 README 写清楚：EDA/结构软件及版本、如何打开工程、
GPIO 表、屏幕/功放/麦克风型号、供电电平、引脚冲突、已测试项和待验证项，
以及 CodePulse 根提交、固件版本和编译选项。源文件与导出物放在同一 PR，
不覆盖其他 revision，不把仅成功编译写成实机通过。

原创硬件的公开许可由硬件贡献者在上传时明确；软件根 MIT 不应被当作所有未来
硬件文件的默认许可。第三方封装/符号/模型各自保留来源和许可证，避免带入商业
NDA 资料、订单个人信息和未获授权的供应商文件。导出文件可正常入库，大文件
先评估体积，不提交 EDA 缓存、自动备份或整套工作站目录。

当前已实现的 Board1 引脚与限制见[固件板型说明](../firmware/doc/BOARD1.md)。
新增扬声器/麦克风板仍待核对；不据软件预留代码宣称新硬件可用。
硬件和固件在一个根仓库审查，目录归属和协作见[REPOSITORY](../docs/REPOSITORY.md)。

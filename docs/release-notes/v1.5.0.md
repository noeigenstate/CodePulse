## v1.5.0

### 更新内容

- 桌面端、HUD 与墨水屏固件合并为一个 CodePulse 项目：同一份工作状态、CLI 接入和设备接口；两个桌面预览直接使用固件的 400×300 渲染器，所见即屏上所得
- 界面重构：侧栏只保留「控制 / 桌边内容 / 待办与助手 / 用量统计」，墨水屏状态以侧栏状态条常驻显示；控制页把节目单、显示方式和应用操作收拢到一处，只有改动时才出现应用按钮，未连接时改动会在连接后自动应用
- 墨水屏新增月历卡片（农历、节气、节日与法定节假日）、桌面宠物（新增小狐狸与小猪，原生分辨率线稿）和像素字体，文字更清晰
- 新增本地待办与提醒，可加入墨水屏节目单
- 新增「元宝搜索」桌边卡片（默认关闭）：天气、金价、股票行情、常用 AI 工具更新、今日要闻和节假日公告；密钥只在设置中填写并加密保存在本机，可设置每日请求上限与静默时段
- 元宝卡片在墨水屏上改为专用三色排版（固件 0.0.30-life）：大号像素数字、红色只标出上涨、限行、要闻序号和放假日期，并配一套像素图标；假日安排未公布时显示距下一个节日的天数。需要重新刷写固件后在设备上生效，旧固件仍显示文字卡
- 新增工作语音提醒：桌面端与墨水屏分别开关，只在需要你介入或出现异常时播报，合并提醒且至少间隔 60 秒
- 只是浏览历史会话不再生成或重新激活任务；用量页隐藏路径、密钥等敏感片段
- 控制页以墨水屏预览为主、设置栏收窄；非最大化窗口下各页面保持左右分栏
- 侧栏可直接切换中文 / English；Windows 标题栏颜色跟随浅色与深色主题

# B 波形文字往返实验（0.0.5-text-probe）

目标：在用户认可的低干扰程度下，验证真实字形、数字擦除及短期残影累积。
本版默认关闭；2026-10-21 已由独立 0.0.6-text-timing 对照版替换，以下是本版历史实测。2026-10-21 基准通过，首次 B 文字更新驱动 1.113 秒，用户认为过程舒适、新字清楚，但残影影响阅读。已人工停止剩余往返；请勿再短按，程序不会自动继续。详见文末实测记录。

## 已有依据

2026-10-21 同机 A/B 对照中，A 的刷新为 593 ms，B 为 1,113 ms；B 写黑更深、
擦白残红更少，窗口外内容稳定。用户已明确 B 的变化过程仍舒适、可以接受；
残红能看出，但不非常明显，介于无感和有感之间。它可作为下一轮候选，尚未
证明真实文字可读性、多轮更新或长期稳定性。

本实验直接复用 `../epd-quiet-probe/driver_quiet.inc` 与 `quiet_lut.h`，始终选择
`QUIET_LONG_PAIR`（50/1/4/50，重复次数 1）。驱动和 LUT 未作数值/时序修改。
仍只操作已测试的全宽 400×40 窗口 y=184..223，不扩大区域、不修改电压或 PLL，
不写 OTP。数值来源及控制器家族说明保留在[原实验](../epd-quiet-probe/README.md)。

## 画面与步骤

屏幕标明 CODEPULSE TEXT / TEST DATA。**所有数值是固定测试样本，不是实际额度。**
上方 WAIT 01% / RUN 12% 为原厂全刷产生的静态清晰样本；下方横带切换
CODEX WAIT 01% 和 CODEX RUN 12%。固定 CODEX 字样也位于横带内，可检查保持
黑色的文字是否逐次变淡。标题、参考字和分隔线应保持不动。

开机不刷新。确认 TEXT READY 后，每次只短按一次，观察完且至少间隔 180 秒
才决定下一次。全程最多一次基准加四次差分，没有自动循环：

| step | 驱动 | 下方目标 | 重点 |
| --- | --- | --- | --- |
| 0 | 原 OTP 全刷 | CODEX WAIT 01% | 清除当前残红，建立清晰基准；约 16 秒闪烁 |
| 1 | B 差分 | CODEX RUN 12% | 新文字能否一眼辨认，旧字/数字是否干扰 |
| 2 | B 差分 | CODEX WAIT 01% | 反向擦写，比较第一次基准和上方参考 |
| 3 | B 差分 | CODEX RUN 12% | 与第一次 RUN 比较，是否累积残影/偏色 |
| 4 | B 差分 | CODEX WAIT 01% | 两个来回后是否仍易辨认；随后停止 |

每次均检查舒适度、旧字残影、当前状态和百分比是否明确、固定 CODEX 字样与
外部参考是否稳定。轻微底色按用户感受记录，不直接等同于失败；若旧字导致
难以辨认当前内容、残影明显累积或外部被扰动，应停止操作，不完成剩余步骤。
四次更新仅为短期筛查，不能作为长稳或不同温度下的适配结论。

## 新旧帧与故障处理

首次成功基准后缓存 OLD；每次成功传输后更新为该次命令的目标画面。缓存是
**最后发送的目标**，不是光学读取到的真实像素，因此目视判定仍不可省略。
本轮明确测试轻微残影条件下往返后的影响，不能假定每一步都完美成像。

发生通信/BUSY 故障时保留原 OLD，不重试、不继续推进步骤，安全清理后释放
整板供电。沿用实际驱动的 1 秒 BUSY 起始限制和 30 秒完成限制。短按过早会
被 180 秒冷却阻止；刷新期间累积的短按丢弃，长按在清理后处理。

## 编译与回归

独立选项 `CODEPULSE_EPD_TEXT_PROBE=ON`，其余 WINDOW/WAVEFORM/QUIET 均 OFF。
四个实验互斥，默认全部 OFF，普通固件继续为 `0.0.3-smart-refresh`。
测试程序绕过 Wi-Fi/配网流程，NVS 配置保留。

从 firmware 执行：

```powershell
.\experiments\epd-text-probe\tests\test-host.ps1
```

主机测试使用真实 C 画布、真实步骤推进代码及共享驱动故障回归，检查：

- WAIT/RUN 的像素差异仅位于目标横带，所有红平面位为空白；
- 0→1→2→3→4 的旧/新帧串接和目标交替；
- 任一步通信失败不改 OLD、不推进、不允许重试；
- 一次基准加四次更新的硬上限；
- 共享驱动的 LUT、窗口、极性、BUSY 超时及逐命令故障清理。

本地独立构建 `CodePulse/.tmpshots/text-probe-build/`，日志 text-probe-build.log、
text-probe-host.log。主机测试也导出实际渲染的两张基准图用于检查。

## 刷写与恢复

`flash-probe.ps1 -Port COM6` 验证实验镜像、分区和原恢复镜像的哈希；只写
0x10000 应用，不自动复位。刷写需要从关机状态持续按住功能/电源键，不能
用 BOOT 代替。刷完完全松开掉电，再按约 5 秒开机、灯亮后松开；开机保留旧
画面，先确认 TEXT READY，再短按建立基准。

## v1.4.0-hud.2

### HUD 修复版

- 同一项目内的多个 agent 继续各自使用独立卡片，并由共享细框归组；状态、计时、上下文、
  注意动效和“已读”操作互不干扰。
- 修复 Codex 启动事件中的原生 `source` 字段覆盖 provider 标识的问题；现在打开 Codex CLI
  后无需先发送消息，项目卡片就会出现，与 Claude 和 Kimi 的行为一致。
- Kimi 账户额度改为在 CodePulse 启动时读取并发布，即使尚未打开 Kimi CLI，也能在 HUD
  底部用量行中显示。
- “项目卡片停留时长”现在统一控制空闲、已取消和已读结果卡片，不再出现部分卡片固定约
  5 分钟消失、部分卡片按设置停留的不一致行为。
- 等待授权或输入时可以用“已读”确认提醒，但卡片仍保持待处理状态；CLI 恢复执行后按钮会
  自动消失，真正完成的项目则显示“完成”，避免把不同阶段都表达成“消灭提醒”。

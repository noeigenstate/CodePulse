# Board1 软件对应的硬件边界

本页描述现有固件实际使用的板型，不替代待上传的 PCB 原理图或制造文件。
新硬件设计由贡献者放在 `hardware/<board>/<revision>/` 并注明许可、已核对的
GPIO 表、BOM、供电和对应固件配置。当前新板音频接线仍未确认。

| 功能 | GPIO |
| --- | --- |
| EPD BUSY / RST / DC / CS | 4 / 5 / 6 / 7 |
| EPD SCLK / MOSI | 16 / 17 |
| 电源保持 / 功能电源键 | 9 / 10 |
| AHT20 I²C SDA / SCL | 11 / 12 |
| 指示灯 / 蜂鸣器 | 15 / 18 |
| 原生 USB D− / D+ | 19 / 20 |
| 电池 ADC | 原 42 网络飞线至 8 / ADC1_CH7；两脚始终保持输入 |

模组 ESP32-S3-WROOM-1-N16R8，16 MiB flash、8 MiB octal PSRAM。
面板是 legacy WFT0420CZ15 400×300 黑白红，不能按别的控制器盲换初始化。
`main/board_pins.h` 是当前构建的引脚来源，`sdkconfig` / defaults 定义 PSRAM 等参数。

GPIO9 必须先保持供电；正常开/关机长按约 3 秒。刷写复位可能释放保持，需当次
持续按住电源键，不按 BOOT。禁止同时从 USB 和 H2 3V3 给板供电。
电池百分比是电压估计，不能据此断言精确充电状态或电池温度。

旧 LumaDesk 音频引脚与 4/5/6/7/16/17 的屏幕信号冲突，不能直接套用。
Board1 音频默认关闭；蜂鸣器不等于 I2S 扬声器。新的功放、PDM 麦克风和
独立说话按键需核对后再启用，不复用现有电源键。

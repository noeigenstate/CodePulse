## v1.8.1

### 更新内容

- Antigravity 使用专属 Logo 与品牌强调色（桌面端为四色悬浮拱形标志，HUD 为单色版本），并修复 HUD 中 Antigravity 名称回落显示为 Claude Code 的问题
- 修复 Linux 与 macOS 上侧边栏左上角未显示 CodePulse 品牌标志的问题
- 支持通过根目录 `.env` 配置桌面端构建期的插件平台地址（新增 `.env.example` 模板），同时支持在 GitHub Actions 发布工作流中通过仓库变量 `CODEPULSE_PLATFORM_URL` 注入平台地址，源码中不硬编码线上地址
- 同步最新墨水屏预览资产至 `0.0.33-status`（对应 Crisp860A 动态黑白红低闪刷新固件 `0.0.68-status-red-crisp`）

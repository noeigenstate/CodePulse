# 红色寄存器波形候选 · 0.0.37-red-lut-probe

继续实现真实红色的移动、擦除、出现和减闪。此候选替换实验驱动中仍沿用原厂
慢波形的部分，不是静态红色加黑白刷新。默认关闭，不更改日常固件行为。
完整调查、来源和验收记录见 [记录](../../doc/RED-LUT-LAB-2026-11-05.md)。

`CODEPULSE_EPD_RED_LUT_PROBE=ON`，同时启用现有 PAIR150/RECT；与其他探针及音频互斥。
开机 OTP 基准后，第一次短按使用完整寄存器三色表，第二次使用只减三个重复数的
短表。两次都将旧红块变成黑字/白底，同时在另一侧生成红块；上下红黑对照不变。
同一路径、同一 100Hz、同一 400×40 区域，分别记录 BUSY 与光学结果。
完整表颜色/带外保持未通过时不得继续短表。任何接口错误安全停机，无重试。

每次完成后至少间隔 180 秒，按键过早或刷新中排队的按键丢弃。两次完成后再短按
返回正常工作；长按正常断电。重启仍进入诊断，日常 0.0.33 恢复镜像另存。
不写电压、VCOM_DC、OTP，不修改 NVS。刷写需要当次持续电源按键确认，只写应用。

`test.ps1` 执行实际完整驱动的 SPI/寄存器模型、帧像素和控制流程测试，Debug/NDEBUG
各执行一次。软件检查不能证明红色显色、残影或带外稳定。0.0.37已刷入并由USB身份确认；
用户确认原厂基准正常；寄存器两次实测均为15237ms，未产生减闪效果。

实测补记：FULL/SHORT均为15237ms驱动、15506ms总耗时。用户确认内容正常，
但闪烁没有明显减少。两步未覆盖整条区域红色全部消失，不能认定此前褪色
已修复。详见实验记录末尾；本候选未进入生产。

Current update (0.0.16): HUD titles now use Noto Sans SC 20px / 700 for
both Latin and Chinese, with one shared baseline. Latin advances come from
the face metrics; CJK advances remain 22px. The 16px native body, metadata,
status, brand, quota digits and large native-bold usage headings are unchanged.

CodePulse body/title bitmap composite — SIL OFL 1.1

Current title hierarchy (0.0.15):
- Chinese body remains the accepted native ZhengGeDianHei 16px bitmap,
  fixed 16px advance. Status labels, metadata, brand and quota digit pixels
  remain unchanged. A sparse status face avoids duplicating a full CJK atlas.
- HUD titles use a separate 20px/700 Chinese bold mask, fixed 22px advance
  with side space. Latin titles use native Terminus 10x20 bold. Both wide and
  dense title line boxes are 24px; dense cards reserve two lines for titles.
- Usage account names use native Terminus 16x32 bold (36px padded line box).
  Its Latin capital ink is 20px tall, distinct from the 16px body grid.
- Chinese TITLE is deliberately a separate larger bold face, not the
  native body font enlarged or dilated. It is generated from Noto Sans SC
  at 20px, weight 700, threshold 128, with whole glyph ink retained.
- generate-title-font.py uses Pillow 12.3.0 and the pinned upstream Noto
  source below. Build/regeneration of the atlas itself only needs Python's
  standard library plus the checked-in BDF sources.
- Atlas: 391090 compressed bytes in flash; 2627928 bytes in PSRAM.

Raster contract:
- Chinese: fixed 16px advance; original native pixels, regular bitmap weight.
- Latin body: native 8x16 normal; title/brand: native 8x16 bold.
- Metadata: native 6x12; quota digits: native 10x18 / 10x20 bold.
- No rescaling, outline rasterization, greyscale thresholding, artificial
  dilation, temporal dithering or per-glyph advance corrections.
- Source baselines are retained with 2px top padding. Four vertical padding
  pixels keep the established layout line heights (20/16/22/24).
- All Chinese faces share the same unmodified source strokes. Emphasis uses
  the existing filled status badge; Chinese counters are not thickened shut.
- 7,752-codepoint repertoire retained: GB2312, Latin-1, general punctuation,
  and visible U+FFFD fallback. Unsupported/control glyphs use that fallback.
- Atlas: 290127 bytes compressed in flash; 1496136 bytes expanded in PSRAM.
- Generated composite is named CodePulse Pixel16, not an upstream font name.

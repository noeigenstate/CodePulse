## v1.8.0

### 更新内容

- 左边栏可以收起：点边栏右上角的按钮，或按 Ctrl+B（macOS 为 ⌘B），收起后只留 56px 宽的图标栏，悬停或键盘聚焦图标时显示名称，下次打开保持上次的状态；在输入框里打字时快捷键不触发
- 左边栏按分组重新排列：工作空间（工作台、悬浮窗）、设备与扩展（墨水屏设备、插件）、数据分析（用量与费用）。「主窗口」改名「工作台」，「开销」改名「用量与费用」，「插件」不再挂在墨水屏设备下面
- 边栏底部新增运行状态条，显示「运行正常 · N 个任务执行中」或「运行正常 · 空闲」，只统计设置里没有隐藏的 CLI；墨水屏的连接状态改为设备图标上的小圆点，空心表示未连接，实心绿点表示已连接
- Windows 上去掉了单独的标题栏和顶边横线：CodePulse 标志和名字放在边栏顶部，内容区一直延伸到窗口顶部，右上角的最小化、最大化、关闭按钮和内容区同色
- 去掉界面上重复的信息：各页的大标题和副标题（与边栏选中项重复）、悬浮窗页的第二个标题、插件列表每行的「本机 · 随应用自带」
- 删除「专注模式」，以前保存的专注模式设置会被忽略
- 「语音提醒」和「状态中英文对照」移到设置页；语音提醒分工作台、墨水屏设备两个独立开关，用法和以前一样
- 墨水屏设备页的「画面预览」和「节目单」两张卡片等高，标题对齐

# CodePulse 主板 · V3

带功放和麦克风的 CodePulse 墨水屏主板。丝印为“不负芳华V3”，原理图图框写作 V1.0，
本目录以板上丝印 V3 为准。

> **状态：未经实机验证。** 这里只有导出文件，可编辑源文件、BOM 和设计许可证还没有上传。
> 现有固件按 [Board1](../../../firmware/doc/BOARD1.md) 构建，音频默认关闭，不能直接用于本板的功放和麦克风。

## 规格

| 部分   | 型号与说明                                                               |
| ------ | ------------------------------------------------------------------------ |
| 主控   | ESP32-S3-WROOM-1-N16R8                                                   |
| 屏幕   | 400×300 墨水屏，24-pin FPC，板载升压电路                                 |
| 功放   | MAX98357A，I²S 输入，PH2.0 喇叭座                                        |
| 麦克风 | MSM261DGT003，PDM 输出                                                   |
| 传感器 | AHT20 温湿度，I²C                                                        |
| 电源   | USB-C 5V 输入，BQ24075 电源路径管理，锂电池充电电流设为 300 mA，3.3V LDO |
| 按键   | BOOT、RESET、多功能按键；开机后由电源保持电路维持供电                    |
| 调试   | H2 四针串口调试孔                                                        |
| 板子   | 4 层板，45.3 × 77.0 mm                                                   |

GPIO 分配见原理图第 2 页。完整 GPIO 表还没有和固件核对，暂不在这里列出。

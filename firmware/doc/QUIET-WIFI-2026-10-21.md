## 用户可见行为

- 开机先连接已保存的 Wi-Fi、读取真实 agent 数据，再做一次原 OTP 清洁全刷，清除旧红色并建立纯黑白基准。原有 NVS 配网保持，USB 配网及 LAN 健康服务恢复。
- Codex 放在原验证的 y=96..135 横带；Claude 在 y=156..195，Grok 在 y=216..255。状态字体沿用实验的 3 倍点阵字号；额度为清晰的 2 倍字号。Claude 显示 5H/WEEK，其余为 WEEK；都是已用百分比，未知显示 --%，未开启的 agent 仍为 OFFLINE。
- 后台每 30 秒空闲等待后取数。可见额度变化、持续 60 秒的状态/连通性变化触发局部更新；距上次显示尝试结束至少 180 秒。短按请求同步最新数据，也遵守屏幕间隔，过早短按排队后自动完成。
- 小幅温湿度/电量变化不单独触发刷新，也不扩大 agent 的刷新区域。手动同步可以带上最新读数。累计至少 1°C、5 个湿度百分点、10 个电量百分点或读数有效性改变，至少间隔 15 分钟才能自动更新传感器区；计时独立于 agent 行，避免不断更新 agent 时传感器被永久饿死。
- 只更新包含变化行的全宽窗口。多行同时改变时合并成一个窗口、执行一次波形；单独 Codex 变化仍是 400×40。窗口之间未变的像素使用 OLD/NEW 相同数据。温湿度/连接/电池区为 y=48..87；最大合并范围 y=48..255。
- 无像素变化不发送刷新命令。普通更新不全刷；不自动定时清屏、不在失败时悄悄退回全刷。若需清除长期淡印，可主动关机后开机建立新基准。
- 每次成功传输后才更新 OLD 缓存和屏幕模型。故障不推进缓存、不自动重试；通过现有安全关机路径停止 Wi-Fi、准备面板休眠并释放供电，避免未知状态反复驱动。长按关机行为保留，刷新期间的短按丢弃。

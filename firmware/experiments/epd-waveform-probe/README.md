# 当前入口：寄存器 LUT 生效诊断（v2）

当前源码/构建版本为 `0.0.3-waveform-probe2`，已通过目标构建和实际驱动主机测试，**已于 2026-10-21 刷入并校验通过**。当前设备运行 v2，HALF 已完成：16.058 秒，缺红、黑字变淡，判为失败；已停止后续波形，等待恢复日常固件。实测记录见文末。下文的三阶段流程是 v1 历史，不是 v2 操作步骤。

v1 完整参考表与重复数减半表均耗时 15,835 ms。用户观察“貌似是减少了”，但没有测得耗时下降，尚不能认定 LUT 控制或减闪成功。下一步先诊断参数是否生效，避免继续盲目删减。

v2 将三色模式及四张易失 LUT 的加载提前到 POWER_ON 前；这来自参考驱动的顺序对照，尚不能认定加载顺序就是原因。不改电压、PLL，不写 OTP。

| 操作 | 预期和停止条件 |
| --- | --- |
| 正常开机 | 不刷新，保留当前物理画面；日志 READY 后才能手动测试 |
| 首次短按：ZERO | 发送全零 LUT，目标内容为 ZERO TRY / RED 44。如果参数生效，预期像素不变、耗时短；必须同时核对日志和目视 |
| ZERO ≥2 秒 | 自动停止，禁用后续 HALF；不代表硬件永远不可控，只表示本路径没有证明参数生效 |
| ZERO <2 秒 | 等用户确认像素未变，并冷却至少 180 秒后，才考虑再次短按 HALF |
| 第二次短按：HALF | 同一 400×40 窗口，显示 HALF TRY / RED 55；仍需确认翻转、颜色、残影和耗时，完成后停止 |

仅 ZERO 在实际发出刷新命令后，允许 BUSY 短到采样未捕获；命令、初始化失败及 BUSY 持续低电平均仍报错并关断。不自动触发实验，不自动重试。实验无 Wi-Fi/配网，不改 NVS。实验完成后仍需恢复日常固件。

应用 396,768 字节，SHA-256 `F9980879D90EBA98B8C67B9A89B6BEE27CB3024297C13C49226DB3C5A7EEFDB5`。分区和恢复镜像校验不变。刷写脚本核对当前清单，仅写应用 0x10000，仍需用户持续按住功能/电源键。日志 `waveform-probe2-build.log` / `waveform-probe2-host.log`；主机故障测试另外确认 ZERO 不掩盖各命令的失败。

# 原型三色刷新波形 A/B 实验

目标是改变窗口内的黑白翻转次数和时间，不以缩小字体或刷新区域代替这个问题。
本实验与已通过的 OTP 横带实验分离，普通构建默认不启用。

## 波形来源与未确认项

数值来源：[Arduino Forum 第 427 帖，beee，2018-03-03](https://forum.arduino.cc/t/waveshare-e-paper-displays-with-spi/467865?page=22)，标注为 GDEW042Z15 的三色 LUT。驱动作者随后解释三色模式不使用旧/新帧的 WW 差分表。已核对 VCOM、R、W、B 四张表的字段及长度。

这不是从本机 OTP 读出的数据，也没有取得厂家对这块 WFT0420CZ15 LW 玻璃批次的认证。厂商历史下载页仍可读，但指向的 GDEW042Z15SC 压缩包返回 404，不能将社区公开表标为“已向厂家确认”。所以必须先做完整表的本机显示对照，不能直接删减后宣称可用。

## 三个阶段

| 阶段 | 波形 | 画面 | 用途 |
| --- | --- | --- | --- |
| 开机基准 | 原屏内 OTP，不改变原驱动 | OTP BASE / 红色 RED 11 | 建立本机正常颜色和静态对照区 |
| 第一次手动短按 | 公开完整三色表，易失寄存器 | REG FULL / 红色 RED 22 | 先检查参考波形是否适合本机玻璃 |
| 第二次手动短按 | 同表，仅三个重复阶段减半 | REG HALF / 红色 RED 33 | 比较翻转次数、耗时、颜色和残影 |

两次寄存器试验使用相同的全宽 400×40 窗口（x=0..399，y=128..167，PT_SCAN=0）。不改变窗口尺寸，因此不会把面积变化误认为波形改进。

删减表只将第 2、3、4 组的重复字段 `8 / 16 / 8` 改成 `4 / 8 / 4`。所有电平编码、组内持续帧数及其他阶段字段保持一致。参数中的“持续帧数×重复数”总和由 1157 降到 757；这只是参数对照，不能据此宣称实际耗时或闪烁次数按同一比例缩短。

## 固件边界

- 版本 `0.0.3-waveform-probe`；`CODEPULSE_EPD_WAVEFORM_PROBE` 与窗口实验开关互斥，默认均为 OFF。
- 保持三色模式；`PANEL_SETTING` 只从 `0x0F` 改为 `0x2F` 以选择寄存器 LUT。仅加载 `0x20/0x22/0x23/0x24` 的 VCOM/R/W/B 表，不借用黑白玻璃的 LUT。
- 不写 OTP，不改驱动电压寄存器、不改 PLL 频率。复位重新初始化后仍可回到屏内 OTP。
- GPIO9 优先保持供电，GPIO42/GPIO8 保持输入，BUSY 上限 30 秒，刷新结束执行高压关闭。若任何试验步骤报错，释放整板供电并停止，不自动重试；不会在失败状态下等待下一次冷却。
- 仅手动触发，完成后不再刷新；每次之间至少 180 秒。参考表颜色不正确时，不应继续按键进入删减表试验，应终止并恢复原固件。
- 没有 Wi-Fi 同步或 USB 配网服务，不修改 NVS。当前构建只是实验，不代表快刷已交付。

## 目视验收

先确认 REG FULL 阶段的黑字、红色 RED 22、窗口外红/黑控制区均正确，才继续第二次短按。
REG HALF 阶段同时检查：翻转次数与持续时间是否下降、红色 RED 33 是否完整、黑字对比度、旧字残影、窗口外是否仍稳定。
通信返回 ESP_OK 不能替代这些目视结论。若删减后红色不完整或残影增加，记录为失败或有条件结果，不能自动用于日常看板。

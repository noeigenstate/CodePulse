## v1.4.11

### 更新内容

- 新增 Linux arm64（aarch64）AppImage：`CodePulse_<版本>_arm64.AppImage`，与 x64 版一同发布，并各自支持 AppImageUpdate 增量更新
- 卸载时把 Claude Code / Codex / Grok / Kimi 的配置还原为安装 CodePulse 之前的状态：未改动过的文件逐字节还原，CodePulse 新建的文件会删除；接入后你手动改过的内容会保留
- macOS / Linux 托盘菜单新增「还原 CLI 配置并退出…」，删除应用前使用即可（Windows 卸载程序会自动还原）
